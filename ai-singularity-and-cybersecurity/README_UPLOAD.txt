Deployment
----------
1. Upload the entire contents of this folder to the target web directory.
2. Preserve the assets/ directory structure.
3. Confirm that your host serves .webp as image/webp.
4. Open the deployed page and test the PDF and full-resolution figure links.
5. If the final page URL differs, update CANONICAL/og:url references in index.html.
